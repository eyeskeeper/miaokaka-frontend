# 审核上诉与举报前端（救济通道入口 / 组长仲裁卡 / admin 举报页签）

> 归档日期：2026-11-09。前端 bac3a98；后端配套见 miao-kaka 仓库 470aa72 与 specs/2026-11-09-appeal-report-design.md。

## 改动一览

### 详情页（pages/duel/detail.vue）
- **审核记录卡**：
  - 驳回条目按规则出操作按钮（仅本人的被驳回凭证，进行中，未改判）：
    - 互审局 + 未上诉 + 驳回 48h 内 → 「⚖ 上诉」（前端按 reviewTime 判窗口）
    - 组长局，或互审局上诉被维持（appealStatus=2）→ 「🚨 举报」（myReported 为真则不再显示）
  - 「⚠ 已被改判」红色公示标记（overturned，覆盖上诉与举报两种改判来源）
  - 上诉状态文案：待仲裁（超时自动改判）/ 上诉改判通过
- **组长仲裁卡**（互审局组长 + 进行中）：凭证图 + 原驳回理由 + 上诉理由 + 仲裁截止时间（逾期自动改判提示）；【改判通过】确认弹窗说明补钱+补结算，【维持驳回】提示对方可升级举报
- **理由弹窗**：上诉（必填 ≤255）/ 举报（必填 ≤255），复用弹劾弹窗样式
- load() 联动：互审局组长加拉 appeal/pending 与 history

### 管理后台（pages/admin/users.vue）
- 第三页签「🚨 举报处理」（带待处理计数角标）：状态筛选（全部/待处理/已改判/已维持）+ 分页
- 条目：举报人/局名/局状态标签、被举报凭证图（可预览）、原驳回理由、举报理由、上诉链（状态+理由）、处理备注
- 【改判通过】（局非进行中时拦截提示）/【维持原判】确认弹窗

### 消息中心（pages/profile/messages.vue）
- typeIcon：8=⚖（收到上诉）/ 9=✅（上诉举报结果）

### 类型与 API
- `types/api.ts`：AppealPendingVO、ReportAdminVO、ReviewHistoryVO +evidenceId/appealStatus/appealReason/overturned、DuelVO +appealPendingCount/myReported
- `api/duel.ts`：appealEvidence / getPendingAppeals / resolveAppeal / reportDuel
- `api/admin.ts`：getReportPage / resolveReport
