# 2026-09-24 好友系统 + 点赞小鱼干 + 计划模板市场

## 背景与目标

补齐社交链与模板玩法三件套（对接后端 /friend、/template、/mall/exchange-fish）：

1. **好友系统**：申请-同意制好友关系；好友排行（私域全勤榜）；好友打卡动态 feed
2. **围观/点赞**：围观好友的猫与打卡日历；点赞好友打卡，被赞者得小鱼干（1:1 兑积分，商城联动）
3. **计划模板市场**：官方/用户公开模板，一键套用建计划；AI 草稿一键存为模板

## 一、好友页（pages/friend/friend.vue）

- 收到的申请：同意（双向写入）/ 拒绝
- 添加好友：按账号或用户 id 搜索 → 定位后发申请
- 好友列表：头像/昵称/全勤连击，支持删除（双向）
- 好友动态：好友近 7 天打卡，卡片带「👍 点赞送小鱼干」（已赞置灰），实时更新点赞数

## 二、围观页（pages/friend/friend-detail.vue）

- 好友的猫窝：其全部进行中计划的猫（Lv./名字/所属计划/BOSS 击败数）
- 只读打卡日历：点某只猫展开该计划月历，支持前后翻月（正常/补卡色块）

## 三、模板市场（pages/template/market.vue）

- 市场列表：官方标置顶 → 使用量 → 最新；展示类型/天数/任务数/创建者
- 创建模板：名称/描述/类型/目标天数/任务清单（≤5）
- AI 生成模板：一句话描述 → 复用 /ai/plan/draft → 映射字段直接入库
- 一键套用：确认后 POST /plan/from-template 直接建计划；创建者或 admin 可删除

## 四、排行榜（pages/ranking/ranking.vue）

- 新增「🌐 全站 / 👫 好友」segment；好友榜按全勤连击倒序；无好友时空态引导去好友页

## 五、商城（pages/mall/mall.vue）

- 新增小鱼干余额卡（来自 userStore.userInfo.driedFish）+「1:1 兑积分」按钮
- 兑换后同步刷新积分

## 六、基建

- `api/friend.ts`（11 函数）、`api/template.ts`（3 函数）、`api/mall.ts` 加 exchangeFish、`api/checkin.ts` 加 getAchievementWall 与 makeup useVoucher 参数、`api/plan.ts` 加 applyPlanTemplate
- `utils/request.ts` 的 `del` helper（DELETE）
- `pages.json` 注册 3 个新路由
- 登录态缓存 5 分钟：SQL 改角色后需清 Redis `miaokaka:user:{id}` 或等 TTL 过期再联调权限类功能

## 七、验证

- `vue-tsc --noEmit` 通过；`uni build`（H5）通过
- 接口行为均已在后端冒烟（好友全链路/点赞日限/1:1 兑换精确断言/模板套用与删除权限）

## 八、明确不做

好友上限与拉黑、非好友围观、点赞推送通知、feed 深分页、模板编辑与版本、AI 直接发布官方模板
