# 2026-09-24 组队打卡模式前端

## 背景与目标

后端新增组队打卡玩法（`duel.mode`：0=押金死斗 / 1=组队打卡——无押金无奖池，进行中可自由加入/退出，凭证审核保留）。前端补齐玩法选择、展示与筛选，普通用户与组队局零感知差异。

## 一、创建页（pages/duel/create.vue）

- 新增「玩法类型 *」segment（首个表单项）：⚔️ 押金死斗 / 🤝 组队打卡（免押金，进行中可自由进出）
- 组队打卡模式：隐藏押金输入项；提交按钮文案切换为「🤝 创建组队打卡」；`depositPerMember` 不传（后端落库存 0）
- 押金校验仅在押金死斗模式执行

## 二、死斗详情页（pages/duel/detail.vue）

- 头部统计：组队局显示「免押 / 组队打卡」，押金局不变
- 成员行：组队局隐藏「押金 X」后缀
- 加入按钮：组队局「🤝 免押加入」；退出按钮：组队局**进行中也可退出**（按钮文案「退出组队」，确认弹窗与 toast 不再提押金退款）
- 一键通过确认弹窗文案按 mode 区分（组队局不提"扣除押金"）

## 三、招募大厅（pages/duel/hall.vue）

- 条目：玩法标签（组队打卡/押金死斗）+ 押金 chip（组队局显示「免押金」）
- 新增「玩法」筛选行：全部玩法 / 组队打卡 / 押金死斗（本地过滤，与加入方式筛选同模式）；清除筛选一并重置

## 四、我的死斗列表（pages/duel/list.vue）

- 副标题押金展示按 mode 区分（组队局显示「免押金」）

## 五、类型与接口

- `DuelCreateRequest.mode?`、`DuelVO.mode`、`HallDuelVO.mode`（后端均已下发）
- 对接后端 `GET /duel/hall?mode=` 服务端筛选能力（当前沿用本地过滤，分页翻页时可切换为服务端筛选）

## 六、验证

- `vue-tsc --noEmit` 通过；`uni build`（H5）通过
- 后端双模式冒烟见后端仓库 `docs/superpowers/specs/2026-09-24-team-mode-design.md`
