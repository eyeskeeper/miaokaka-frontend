# 2026-09-20 组长治理界面 + admin 用户管理页

## 背景与目标

后端接口对账发现 10 个端点无前端入口：死斗治理 4 个（移除成员/让渡组长/发起弹劾/弹劾投票）+ 管理端用户管理 6 个（增查改删/分页/封禁）。本轮全部接上，且普通用户不可见：

- 组长治理做在 `pages/duel/detail.vue` 内（不新建页面），按 `myRole`/`isMember` 门控
- admin 用户管理为独立页面 `pages/admin/users`，入口仅 admin 角色可见

另含一处既有缺陷修复：大厅分页参数。

## 一、组长治理（pages/duel/detail.vue）

- **成员行内按钮**（仅 `isLeader` 且非自己一行）：
  - 「让渡」：确认弹窗强提示"你将变为普通成员，全部组长权限随之转移"，成功后对方成为新组长
  - 「移除」：确认弹窗说明退款规则（招募中全额退款；进行中按剩余天数退款，缺勤份额入奖池）
- **弹劾（进行中死斗）**：
  - 非组长正式成员：操作区「发起弹劾组长」按钮（无进行中弹劾时）→ 手写弹窗输入原因（≤20 字），发起人自动记 1 张弹劾票
  - 进行中弹劾卡片（红边）：原因/发起人/弹劾票·维持票/投票基数/截止时间，全员可见
  - 投票：未投票的正式成员显示「投弹劾」「投维持」双按钮；**组长只显示「投维持」**（后端拦截组长投弹劾票）；已投显示"我已投：弹劾/维持"
- 所有治理操作成功后重拉详情（`duelStore.applyDuel` 同步列表 store），弹劾成功导致的组长变更实时反映
- 后端错误文案原样 toast（如「弹劾进行中，不能移除弹劾发起人」「该死斗已满员」）

## 二、admin 用户管理（新页面 pages/admin/users）

- **入口**：`pages/profile/profile.vue` 菜单「🛡 用户管理」，`v-if="isAdmin"`（`userStore.userInfo?.userRole === 'admin'`）；页面 onLoad 二次守卫（非 admin toast 后 navigateBack）；后端 `@AuthCheck(mustRole="admin")` 第三道保险
- **列表**：`GET /admin/user/page`，昵称模糊搜索 + 角色筛选（全部/普通/管理员 segment），行内展示账号/昵称/角色标签/连击/积分/注册时间；上一页/下一页 + 页码
- **新建弹窗**：账号（4~32 位）/ 初始密码（8~32 位）/ 昵称（可选），创建赠 1000 喵币
- **编辑弹窗**：昵称 / 头像（URL 手输或 `uploadImage` 上传）/ 角色 user↔admin 切换 / 重置密码（留空不改）
- **封禁/解封**：确认后 `POST /admin/user/ban`，封禁即时踢下线（后端逐出登录态缓存）
- **删除**：确认后 `DELETE /admin/user/{id}`（逻辑删除+账号归档；名下有招募中/进行中死斗押金时后端拒绝，文案原样提示）
