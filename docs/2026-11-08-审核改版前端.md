# 审核改版前端（审核方式选择 / 互审派单视图 / 审核公示 / 解散强确认）

> 归档日期：2026-11-08。前端 14c7238；后端配套见 miao-kaka 仓库 faa71ab 与 specs/2026-11-08-review-mode-design.md。

## 改动一览

### 创建页（pages/duel/create.vue）
- 新增「凭证审核方式」chips：🛡 组长审核（默认）/ 🔄 组内互审（每日轮换互相审，组长也被审），复用 joinMode 的 mode-chip 样式
- 新增「🤖 AI 预审」toggle（复用隐藏局的 hide-switch 样式），说明文案"AI 判通过直接免人工，建议驳回转人工复核"
- 提交参数带 `reviewMode` / `aiReview`

### 详情页（pages/duel/detail.vue）
- **招募期设置卡**（组长 + status=0）：审核方式 chips + AI toggle + 保存（`PUT /duel/{id}`，开赛后锁定后端拦截）
- **待审区按模式分视图**：
  - 组长审核局：现状（仅组长，全量带按钮）
  - 互审局：`🔄 派给我的待审`（全员含组长，scope=mine，带通过/驳回）；组长额外 `👁 全队待审（只读）`（scope=all，无按钮，条目显示"待 xx 审"）
- **审核记录公示卡**（进行中 + 成员）：最近 50 条通过/驳回（审核人 / 自审标记 / 理由），`GET /duel/{id}/review/history`
- 打卡区文案随模式切换（"组长审核通过后生效" / "当日轮换的组员互审通过后生效"）
- 移除进行中倒数第二人：`uni.showModal` 强确认（confirmText="解散并移除"），提示小组将立即解散；成功后 toast 区分解散
- load() 联动：互审局成员拉 mine，互审局组长加拉 all + history

### 列表页（pages/duel/list.vue）
- 待审核徽章从"仅组长"放开到互审局全员（后端 pendingCount 已按"派给我的"计数扩展）

### 类型与 API
- `types/api.ts`：DuelCreateRequest +reviewMode/aiReview、DuelVO +reviewMode/aiReview、ReviewItemVO +assigneeName 且 aiSuggestion 改可空（null=未启用）、新增 ReviewHistoryVO / DuelUpdateRequest
- `api/duel.ts`：updateDuelSettings(PUT)、getPendingReviews(duelId, scope)、getReviewHistory

### Bug 修复
- AI 建议徽章方向颠倒：后端口径 `0=建议通过 / 1=建议驳回 / null=未启用`，旧 UI 按 `>0 通过` 渲染且引入了不存在的 -1 三值；`constants/pixel.ts` 的 `aiSuggestionLabel` 同步修正

## 明确不做
派单到达通知、申诉入口、组长代审按钮（后端亦未开放）
